# HomeworkSolver

AI 作業解題平台 — 學生提交題目，AI 生成解題步驟；家長透過儀表板設定科目規則、查看學習記錄。

## 功能
- 多使用者角色（學生 / 家長）
- 家長儀表板：管理科目規則、查看解題記錄
- 錯題本：記錄並複習答錯的題目
- 數學公式渲染（KaTeX）
- 圖片題目上傳

## 技術棧
- React 19 + TypeScript + Vite
- Express.js（BFF）+ Bun
- KaTeX + Recharts + Zustand

## 快速開始
```bash
cd 02-web
npm install
npm run dev
```
